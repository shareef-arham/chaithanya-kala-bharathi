## ⚡ Quick Start

```powershell
# 1. Bypass PowerShell execution policy (Windows only)
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Open in browser: http://localhost:3000
```

---

## 🚀 Deploy to Vercel

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass; npx vercel
```
